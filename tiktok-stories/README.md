# TikTok Stories — Torin Style, Shareable

> 7 scripts in Torin Russell explainers style (question title → hook → human → mechanism → reveal). Each 60–90s, ready to record.

## How Torin Does It

Every Torin explainer: **Question title** (`Why...?` / `How...?`), **Hook in first sentence** (one shocking image/number), **Human chronology** (085 CE? King? *This happened*), **Mechanism** (why it matters geopolitically), **Reveal** (punchline that reframes). Ends with `Keep reading` + sources. TikTok: 3s hook, 60–90s VO, B-roll listed.

## This Folder

- `01-` → `07-` are 7 shareable scripts from the Indianization Lab (Champa→Bali). All have frontmatter `categories: "[[TikTok Stories]]"` so `![[Templates/Bases/TikTok.base]]` lists them instantly.
- **Duration:** ~80s average (180 wpm = ~260 words). Longer Torin originals are ~1700w (see `../original/sources/`).
- **Filter:** Open `Templates/Bases/TikTok.base` in Obsidian — sort by `region` or `hook`.

## Record Flow

1. Read HOOK 3× (first 3s must be spoken over cold open — goddess face, Borobudur drone, Chola fleet).
2. Record VO from `---` to `---` (body).
3. Paste Caption + Hashtags verbatim.
4. B-roll list is shot list.
