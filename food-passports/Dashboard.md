## How to Filter Yourself

- **Only tomato notes?** `Passports.base` → filter `crop` → Tomato, or open any note and add `crop: ["Tomato"]`.
- **Everything about Nepal?** `Kitchens.base` → *All Kitchens*, filter `region` contains Nepal; then trace `potato-to-nepal`.
- **Mainstay (citizens) only?** `Passports.base` → view *Citizens* (filter `mainstay == true`).
