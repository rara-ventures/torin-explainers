# 4th Century CE

**Phase:** Phase 1: Contact  
**Anchor:** Funan tributary to China, Champa Bhadravarman I My Son E1, Gupta golden age begins, Pallava script diverges

**Century overview:** Indianization in Southeast Asia — Brahmins, merchants, and Buddhist monks carry Sanskrit, Pallava script, Dharma, and temple architecture via monsoon trade; local rulers adopt *devaraja* / *cakravartin* to localize.
